### 未加入的项目（无对应计费类型，避免算错）

新表里的 **群名片后缀 20/天、叫醒 15/次、头像单 20/天、歌单 30/首、语音条拉满 20/次**
使用「/天」「/次」「/首」单位，而码单器只支持 **按局(round)** 与 **按小时(hour)** 两种结算方式，
塞进去会导致算价错误，故按约定跳过。若需要，可将单位并入项目名后再加（例如「歌单(首)」30/局）。
